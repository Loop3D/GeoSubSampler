changelog=0.5 - Speed: First Order sampling uses a spatial index (~100x faster); the grid-cell methods (Kent, Kent Outlier, Carmichael) work on arrays (Kent ~55x, Carmichael ~28x, Kent Outlier 5-6x); Visvalingam-Whyatt map simplification, Rescale Map, Merge Segments, Fault Graph and Cluster faults are faster with identical results; heavy libraries load only when needed, so the plugin starts faster. New: Densify Nodes (QGIS and ArcGIS Pro) - one fixed spacing in metres, new nodes shared by the polygons on both sides of a boundary and by faults along it, optional shared nodes where lines cross polygon boundaries. Fault Strat Offset now reads the geology at every fault/contact crossing (start, middle and end only for faults that meet no contact), adds n_samples, n_offset, n_nooffset, n_edge, max_off_x, max_off_y and sample_src, and saves the sample points as *_stratOffset_samples. Cluster faults writes only the best result. First Order resolves equally near contact segments to the best-aligned one. 0.4 - Kent: new, fixed Kent estimator, optional Min kappa filter, count/kappa/beta attributes; Kent Outlier: one outlier per cell by default, optional Iterative mode (several outliers, vectorised so it is fast); new Carmichael iterative outlier method; Grid Cell Avg removed (identical to Kent without kappa); auto-fit to N points much faster; warning when the Dip field holds values outside 0-90 (swapped fields); ArcGIS Pro version updated to match; calcs added to pb_tool extra_dirs. 0.3.1 - Fixed loading on QGIS 4 / Qt6 (scoped Qt and QGIS enum names via qt_compat.py); still works on QGIS 3.x. 0.3 - Added an ArcGIS Pro version (ARCGIS/GeoSubSampler.pyt, Tkinter GUI) with the same point, fault, polygon and Töpfer & Pillewizer tools. The QGIS plugin itself is unchanged.
